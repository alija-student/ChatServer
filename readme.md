# Chatserver Projekt

Ein Echtzeit-Chatserver mit Web-Client, entwickelt als Schulprojekt für die Fächer WMC und SYPPRE.

## Projektziel
Ziel dieses Projekts ist die Entwicklung eines einfachen Client-Server-Chat-Systems, bei dem mehrere Benutzer gleichzeitig verbinden und in Echtzeit Nachrichten austauschen können.

## Funktionen
- Echtzeit-Chat Kommunikation
- Mehrere Clients gleichzeitig möglich
- Benutzername-Unterstützung
- Einfaches Web-Interface
- Server verwaltet die Bentuzer (emailadresse, nickname, passwort)

## Technologien (Tech Stack)
- Frontend: HTML / CSS / JavaScript 
- Backend: JSON
- Kommunikation: TCP
