# Projektauftrag – Chatserver Projekt

## 1\. Projekttitel

Chatserver mit Web-Client

## 2\. Ausgangssituation

Im Rahmen des Unterrichts in den Fächern **WMC** und **SYPPRE** soll ein Projekt umgesetzt werden, das sowohl technische Umsetzung als auch organisatorische Planung beinhaltet.  
Als Projekt wurde ein Chatserver gewählt, der eine Kommunikation zwischen mehreren Benutzern in Echtzeit ermöglicht.

## 3\. Projektziel

Ziel des Projekts ist die Entwicklung eines einfachen Client-Server-Chat-Systems, bei dem mehrere Benutzer gleichzeitig über einen Web-Client Nachrichten senden und empfangen können.

Das System soll benutzerfreundlich sein und eine stabile Kommunikation ermöglichen.

## 4\. Projektumfang

### 4.1 Ziele

* Entwicklung eines Chatservers
* Entwicklung eines einfachen Web-Clients (Benutzeroberfläche)
* Echtzeit-Kommunikation zwischen mehreren Clients
* Anzeige von Nachrichten im Chatfenster
* Benutzername für Teilnehmer
* Benutzerregistrierung mit Datenbank
* Dokumentation (Projektmanagement + technische Doku)
* Tests und Fehlerbehebung
* Anmeldung mittels JSON (Registrierung später per Datenbank)

### 4.2 Nicht Ziele 

* Verschlüsselung / Security Features auf Profi-Niveau
* Mobile App (Android/iOS)
* Sprachanrufe oder Videochat
* Komplexes Design / UI Animationen

* Zeitmangel durch parallele Schulaufgaben
* Technische Probleme bei Echtzeit-Kommunikation (WebSocket / Netzwerk)
* Fehler bei der Benutzerverwaltung oder Nachrichtenverteilung

## 10\. Erfolgskriterien

Das Projekt gilt als erfolgreich abgeschlossen, wenn:

* mindestens 2+ Clients gleichzeitig verbinden können
* Nachrichten in Echtzeit übertragen werden
* Benutzername angezeigt wird
* die Anwendung stabil läuft (keine Abstürze)
* Dokumentation und Projektplanung vollständig im GitHub Repository vorhanden sind
